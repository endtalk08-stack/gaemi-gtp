# Left Context Sidebar

왼쪽 세로 레일에서 목적별 아이콘을 눌렀을 때 나타나는 보조 사이드바 컨테이너다.

## 1차 컨텍스트
- 관심종목
- 최근본 종목

## 기존 시장정보 사이드바와의 관계
- `left-market-sidebar`: 실시간 시장정보, 인기순위, 거래대금, 산업, 테마
- `left-context-sidebar`: 사용자의 관심/최근 기록 및 향후 개인화 메뉴

두 영역은 같은 위치 계열에 존재하지만 책임은 분리한다.

## 표시 방식
기본 화면에서는 닫혀 있다.
세로 레일의 해당 아이콘을 눌렀을 때 필요한 컨텍스트만 연다.

모바일에서는 기존의 좌측 오버레이/폭 정책과 충돌하지 않도록 별도 상태로 관리한다.
