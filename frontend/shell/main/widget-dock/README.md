# Main Widget Dock

중앙 Workspace 상단의 `+`에서 분석 위젯을 추가할 수 있도록 예약된 구조 영역이다.

## 역할
- 중앙 화면의 위젯 배치 영역을 관리한다.
- 위젯 추가/삭제/순서 변경을 담당할 자리다.
- 위젯의 실제 데이터/API/분석 로직은 담당하지 않는다.

## 예정 화면 흐름
`중앙 Workspace → 상단 + → 위젯 선택 → 중앙 위젯 추가`

## 예시 위젯
- 왜 올랐을까?
- 재료는 있어?
- 차트
- 뉴스
- 거래량
- 거래대금

현재 단계에서는 구조만 예약하며 실제 UI/데이터 연결은 다음 단계에서 하나씩 진행한다.
