# gaemiGTP 구조 개편 2단계

이번 단계는 **오른쪽 패널 우선 설계를 위한 구조 문서와 작업 경계 확정** 단계다.

## 반영
- 오른쪽 패널 Shell의 책임을 별도 문서로 정의
- 대시보드와 패널의 책임 분리
- 위젯은 독립적인 표시 부품으로 정의
- 가운데 기존 데이터/API는 개발 대상에서 보류
- 다음 실제 코드 이동은 오른쪽 패널부터 진행

## 의도적으로 하지 않음
- 현재 화면 런타임 구조 변경
- 가운데 본문 데이터/API 삭제
- engine.py / app.js 즉시 분해
- DB/API 동작 변경

## 다음 단계
오른쪽 패널의 실제 HTML/JS 구조를 한 단위씩 분리한다.
