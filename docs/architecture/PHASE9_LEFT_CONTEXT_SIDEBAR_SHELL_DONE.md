# Phase 9 — Left Context Sidebar Shell

이번 단계는 왼쪽 세로 레일에서 호출하는 **별도 컨텍스트 사이드바의 큰 자리**를 만든다.

## 구조

```text
Left Nav Rail
├── Market Info → Left Market Sidebar
└── Context     → Left Context Sidebar
                    ├── 관심종목
                    └── 최근 본 종목
```

## 동작 원칙
- 시장정보 사이드바와 컨텍스트 사이드바는 동시에 열지 않는다.
- 모바일에서도 왼쪽 레일의 컨텍스트 아이콘으로 별도 사이드바를 연다.
- 모바일에서 컨텍스트 사이드바를 열면 오른쪽 패널은 숨긴다.
- 현재는 구조/자리만 준비하며 저장·DB·로그인 기능은 넣지 않는다.

## 하지 않은 것
- 관심종목 저장/삭제 실제 구현
- 최근 본 종목 실제 기록/DB 저장
- 로그인/인증 연결
- API 데이터 연결
- 기존 시장정보 데이터 흐름 변경
