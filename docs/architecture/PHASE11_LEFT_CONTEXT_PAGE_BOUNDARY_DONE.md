# Phase 11 — Left Context Page Boundary

## 목적
왼쪽 세로 레일에서 열리는 `내 종목` 영역을 실제 데이터 저장 영역과 분리하기 위한 큰 경계를 만든다.

## 구조
```text
왼쪽 세로 레일
└── 내 종목 컨텍스트 사이드바 (shell)
    └── Watchlist Page Container
        ├── 관심종목
        └── 최근 본 종목
```

## 원칙
- sidebar shell은 열기/닫기와 레이아웃만 담당한다.
- watchlist page는 관심종목/최근 본 종목 화면만 담당한다.
- 저장/DB/API/실시간 데이터는 아직 연결하지 않는다.
- 기존 시장정보 사이드바와 오른쪽 패널 구조는 변경하지 않는다.
- 중앙 위젯과 오른쪽 패널 위젯도 변경하지 않는다.

## 정리
이제 `왼쪽 레일 → 패널 shell → 페이지` 경계를 확장할 수 있다.
