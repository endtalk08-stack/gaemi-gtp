# Phase 7 — Global Panel Layout Blueprint

이번 단계는 **큰 화면 구도**만 확정한다. 데이터/API/DB/세부 UI는 건드리지 않는다.

## 확정할 큰 축

```text
┌──────────────────────────────────────────────────────────────────┐
│ LEFT RAIL │ LEFT MARKET SIDEBAR │ MAIN WORKSPACE │ RIGHT PANEL │
└──────────────────────────────────────────────────────────────────┘
```

### 1. 오른쪽 패널

```text
오른쪽 패널
└── 상단 탭
    ├── 대시보드
    ├── 자동매매
    ├── 사용자 추가 분석 탭 ...
    └── + 새 탭
```

탭 안에서는 독립 위젯을 조립한다.

### 2. 중앙 Workspace

```text
중앙 Workspace
└── 상단 +
    └── 분석 위젯 선택
        ├── 왜 올랐을까?
        ├── 재료는 있어?
        ├── 차트
        ├── 뉴스
        ├── 거래량
        └── 거래대금 ...
```

중앙은 대화/분석 영역을 유지하면서 필요한 분석 위젯을 추가할 수 있는 방향으로 확장한다.

### 3. 왼쪽 영역

```text
왼쪽 세로 레일
├── 새 분석 / 검색
├── 시장정보 사이드바
├── 관심/최근본 사이드바
├── 오른쪽 패널
└── 계정
```

기존 시장정보 사이드바와 사용자의 관심/최근본 영역을 하나로 합치지 않는다.

세로 레일의 아이콘을 눌러 별도의 컨텍스트 사이드바를 여는 구조를 기본 설계로 예약한다.

## 이번 단계에서 하지 않는 것

- 주가/API 연결
- DB 저장 구조 변경
- 관심종목 실제 저장 기능
- 중앙 위젯의 실제 데이터 구현
- 위젯 세부 디자인
- 자동매매 실행 기능
- 기존 패널 동작 변경

다음 단계부터는 이 큰 틀을 기준으로 **한 영역씩** 실제 UI/동작을 붙인다.
