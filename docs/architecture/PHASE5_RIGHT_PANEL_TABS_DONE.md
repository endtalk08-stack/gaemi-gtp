# Phase 5 — Right Panel Tabs (v7.5)

## Scope

오른쪽 패널 상단에 탭 컨테이너를 추가했다.

- 기본 탭: 대시보드 / 자동매매
- `+` 버튼: 새 분석 탭 추가
- 탭 `×`: 자동으로 추가된/사용자 탭 삭제
- 선택한 탭: localStorage에 저장
- 새로고침 후 선택 탭/사용자 추가 탭 복원
- 기존 패널 열기/닫기, 최대화, 리사이즈 로직은 수정하지 않음
- Dashboard 위젯 데이터/API/DB/분석 로직은 수정하지 않음
- 자동매매는 화면 영역만 준비하고 실제 기능은 이후 독립 작업

## Reference

사용자가 제공한 `4사이트_html_.html`의 오른쪽 패널 상단 "탭 + 추가 + 탭 삭제" 구조를 참고했다.
단, 현재 gaemiGTP의 고정 오른쪽 패널 구조와 기존 동작은 유지한다.
