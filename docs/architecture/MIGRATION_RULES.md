# 구조 이동 규칙

## 한 번에 하나
- 기능 하나만 이동한다.
- 이동 후 Python/JS 문법 검사
- 서버 시작 검사
- 해당 기능 브라우저 확인
- 이상 없으면 다음 기능으로 진행

## 건드리지 않을 것
- 이미 정상인 UI 동작을 구조 이동과 동시에 재설계하지 않는다.
- 데이터 계산식을 구조 이동과 동시에 바꾸지 않는다.
- API 이름을 구조 이동과 동시에 바꾸지 않는다.
- DB 스키마를 화면 구조 작업과 동시에 바꾸지 않는다.

## 완료 조건
모든 기능이 목표 영역에 들어가고 현재 동작과 비교 검증이 끝난 뒤 레거시 파일을 삭제한다.
