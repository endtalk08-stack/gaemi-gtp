# gaemiGTP 구조 기준선 v7

이 문서는 gaemiGTP를 계속 확장하기 위한 구조 기준선이다.

## 목표
- APP SHELL: 화면의 큰 틀
- DATA: 외부 원천 데이터 수집
- CORE: 여러 데이터 소스를 공통 형식으로 맞춤
- ANALYSIS: 원천/공통 데이터를 계산·가공
- API: 프론트엔드에 필요한 결과 전달
- WIDGETS: 사용자에게 보여주는 화면 부품
- BACKTEST: 과거 데이터/전략/실행/결과를 독립 관리
- USER: 로그인, 관심종목, 설정 등
- ADMIN: 데이터/조건/백테스트/콘텐츠 관리

## 현재 원칙
1. 현재 동작하는 v6 계열을 기준본으로 보존한다.
2. 구조 정리는 기능 변경과 분리해서 진행한다.
3. 새 기능은 먼저 어느 큰 영역에 들어가는지 정한다.
4. 원천 데이터와 가공/분석 데이터의 책임을 분리한다.
5. 위젯은 원천/가공 데이터를 내부에서 함께 사용해도 된다.
6. UI 위젯이 외부 API를 직접 호출하지 않도록 한다.
7. 기존 기능을 깨뜨릴 수 있는 이동은 한 번에 하나씩 수행하고 검증한다.

## 뉴스 대표 키워드 기준선

뉴스 키워드의 목표는 키워드 수를 늘리는 것이 아니라, 기사 핵심을 대표 키워드 3개만 읽어도 이해할 수 있게 만드는 것이다.

1. 일반 분류어와 화면 대표 키워드를 분리한다.
   - `공급과잉`, `자금조달`, `매출발표`, `설비투자` 같은 일반어는 내부 분석 증거/fallback으로 유지할 수 있다.
   - 중앙/화면의 최종 대표 키워드는 더 구체적인 합성 키워드를 우선한다.
2. 대표 키워드는 가능하면 `원인 → 상황/우려 → 결과`를 압축한다.
   - 예: `#메모리증설경쟁 #공급과잉우려 #가격하락우려`
   - 실적: `#잠정실적발표 #분기최대실적 #영업이익100조돌파`
   - 수급 뉴스: `#외국인17조매도 #외국인지분율연중최저 #외국인10일연속매도`
3. 숫자는 단독 키워드로 만들지 않는다. 재무항목/주체/행동과 결합한다.
   - `100조` X, `영업이익100조돌파` O
   - `17조` X, `외국인17조매도` O
4. 기사에 없는 해석을 만들지 않는다.
   - 기사에 단순 `공급과잉`만 있으면 임의로 `공급과잉우려`로 확대하지 않는다.
   - `연중최저`를 `역대최저`로 과장하지 않고 기사에 명시된 범위를 보존한다.
5. 종목/회사 엔티티와 재료 키워드는 데이터상 분리한다.
   - 종목 엔티티: 삼성전자, SK하이닉스, TSMC 등
   - 재료 키워드: HBM수요급증, 메모리증설경쟁, 공급과잉우려 등
   - 화면에서는 필요에 따라 함께 표현할 수 있다.
6. 뉴스에서 추출한 수급 표현은 '뉴스 재료'이며 실제 수급 메뉴 데이터를 대체하지 않는다.
7. 우선순위 예:
   - `대규모자금조달 > 자금조달`
   - `영업이익100조돌파 > 매출발표/실적발표`
   - `낸드시장호황 > 반도체/메모리`
   - `생산능력확대 > 투자계획/설비투자`
8. 산업 뉴스에서 이 품질을 먼저 확보한다. 산업 뉴스에서 원하는 대표 키워드가 안정적으로 생성되어야 이후 테마 뉴스/테마주 연결로 확장한다.
9. 새로운 실제 기사 사례에서 대표 키워드가 밋밋하면 일반어를 무작정 삭제하지 말고, 구체 재료 추출 규칙과 최종 대표 3개 선별 우선순위를 개선한다.

### 다른 작업자/GPT가 지켜야 할 사항

- 키워드 사전을 크게 만드는 것 자체를 목표로 하지 않는다.
- 화면에 일반 키워드를 많이 노출하는 방향으로 되돌리지 않는다.
- 기존 뉴스 수집 체계를 화면별로 복제하지 않는다.
- 기사 근거를 벗어난 호재/악재 해석을 합성하지 않는다.
- 산업 뉴스 대표 키워드 품질을 충분히 확보하기 전에 별도 테마주 뉴스 분석 체계를 새로 만들지 않는다.
