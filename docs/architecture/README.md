# gaemiGTP 구조 기준선 v7

이 문서는 gaemiGTP를 계속 확장하기 위한 구조 기준선이다.

## 목표
- APP SHELL: 화면의 큰 틀
- DATA: 외부 원천 데이터 수집
- CORE: 여러 데이터 소스를 공통 형식으로 맞춤
- ANALYSIS: 원천/공통 데이터를 계산·가공
- API: 프론트엔드에 필요한 결과 전달
- WIDGETS: 사용자에게 보여주는 화면 부품
- BACKTEST: 과거 데이터/전략/실행/결과를 독립 관리
- USER: 로그인, 관심종목, 설정 등
- ADMIN: 데이터/조건/백테스트/콘텐츠 관리

## 현재 원칙
1. 현재 동작하는 v6 계열을 기준본으로 보존한다.
2. 구조 정리는 기능 변경과 분리해서 진행한다.
3. 새 기능은 먼저 어느 큰 영역에 들어가는지 정한다.
4. 원천 데이터와 가공/분석 데이터의 책임을 분리한다.
5. 위젯은 원천/가공 데이터를 내부에서 함께 사용해도 된다.
6. UI 위젯이 외부 API를 직접 호출하지 않도록 한다.
7. 기존 기능을 깨뜨릴 수 있는 이동은 한 번에 하나씩 수행하고 검증한다.


## 현재 진행 위치
Phase 12: 전체 Shell 경계를 고정하는 단계.
오른쪽은 탭→페이지→위젯, 중앙은 +→분석 위젯, 왼쪽은 시장정보와 관심/최근본 컨텍스트를 분리하는 방향으로 자리만 먼저 잡는다.
세부 UI/데이터/API/DB는 다음 단계에서 하나씩 연결한다.

## Phase 8

중앙 Workspace의 Widget Dock과 왼쪽 Context Sidebar의 큰 역할을 분리해 두었다.
실제 기능 구현은 파일 구조 확정 이후 단계에서 하나씩 진행한다.
