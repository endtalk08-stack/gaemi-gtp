# Phase 10 — Central Widget Dock Shell

이번 단계는 중앙 Workspace에도 오른쪽 패널과 같은 방향의 **위젯 추가 구조**를 만든다.

## 구조

```text
Central Workspace
└── 분석 위젯
    ├── + 위젯 추가
    └── 배치된 위젯 자리
        ├── 왜 올랐을까?
        ├── 재료는 있어?
        ├── 차트
        ├── 거래량
        ├── 거래대금
        ├── 뉴스
        ├── 경제일정
        └── ...
```

## 원칙
- 중앙 위젯은 오른쪽 패널 위젯과 공통 카탈로그를 참고한다.
- 중앙의 추가/삭제 상태는 오른쪽 패널과 독립적으로 저장한다.
- 현재는 위젯 이름/자리/추가/삭제만 구성한다.
- 실제 API·DB·계산·렌더링은 후속 단계에서 연결한다.

## 이번 단계에서 하지 않는 것
- 기존 분석 데이터 변경
- API/DB 연결
- 실제 위젯 계산
- 기존 오른쪽 패널 변경
- 관심종목 저장
