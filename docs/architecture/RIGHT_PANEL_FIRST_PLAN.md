# 오른쪽 패널 우선 개발 계획

## 목표
기존 가운데 본문 기능을 당분간 개발 대상에서 제외하고,
오른쪽 패널을 독립된 구조로 먼저 완성한다.

## 진행 순서
1. 오른쪽 패널 Shell 확정
2. Dashboard 컨테이너 확정
3. Dashboard 위젯 배치 확정
4. 각 위젯의 역할 정의
5. 각 위젯의 원천 데이터 / 가공 데이터 정의
6. API 정의
7. DB 저장 필요성 정의
8. 실제 데이터 연결

## 현재 원칙
- 가운데 기존 데이터/API는 당분간 보류한다.
- 기존 코드가 남아 있어도 수정하지 않는다.
- 오른쪽 패널 작업 때문에 가운데 기능을 연결하거나 수정하지 않는다.
- 한 번에 하나의 영역만 실제 런타임 코드로 이동한다.
